# spring-ai-gift-chat

### step 0

- 프로젝트를 클론하고 API 키를 설정하여 애플리케이션을 실행할 수 있다.
- LLM에 간단한 질문을 보내고 응답을 받을 수 있다.
    - 예: "농담 하나 해줘", "오늘 기분이 좋아"
- 시스템 프롬프트를 바꿔가며 같은 질문에 대한 응답이 어떻게 달라지는지 관찰한다.
    - 예: "당신은 요리사입니다" → "당신은 시인입니다"
- 브라우저 또는 curl로 REST API를 호출하고 JSON 응답 구조를 확인한다.

### step 1

#### request & response

- request: 자연어로 선물 추천 요청
    - 예: "친구 생일 선물 추천해줘", "어머니께 드릴 선물 아이디어가 필요해"
- response: 사용자의 메시지에 응답

#### 기능 요구사항

- 서비스는 선물 추천 도우미 역할
- LLM 호출 중 오류 발생 시 안내 메시지 반환 (사용자에게 오류 노출 금지)
- 각 요청의 주요 정보(요청 식별자, 사용자 입력, 응답 생성 시간) 로깅
- 테스트
    - 컨트롤러 테스트는 @WebMvcTest로 웹 레이어만 로드
    - LLM 클라이언트를 mock하여 LLM 호출 없이 로직 검증
    - mock은 Mockito 사용 (Spring AI는 공식 mock ChatClient 미제공)

### step 2

#### 기능 요구사항

- 서비스는 여러 LLM 프로바이더를 지원
- 서비스 계층은 구체적인 LLM 클라이언트가 아닌 추상화에 의존
- 프로바이더는 설정에 따라 전환 가능
    - 프로바이더를 변경하더라도 사용자에게 보이는 응답 형식은 동일
    - 프로바이더 전환 시에도 기존 테스트 통과
